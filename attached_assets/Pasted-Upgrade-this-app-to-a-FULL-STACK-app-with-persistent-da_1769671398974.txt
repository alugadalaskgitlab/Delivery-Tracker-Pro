Roles & Screens

ADMIN (full access)

Can create/manage Parties/Orders (Party Name, Party Code unique, optional Order Ref No, Total Order Qty MT, Active/Inactive).

Can export Excel/PDF, print with an Admin PIN confirmation (PIN required for export/print).

Can reconcile & close orders (‘Reconciled & Invoiced’) and deactivate SITE access tokens.

Has global dashboard + notification log + filters.

PLANT (limited access)

Can create dispatches only (Dispatch Entry Screen). Dispatch auto-generates Challan No (PARTYCODE-0001 sequential per party) and auto dispatch timestamp.

When selecting a Party on dispatch entry, show that Party’s Total Order Qty, Dispatched Qty so far, and Balance Qty.

Can view their own dispatch summary (read-only).

Can view acknowledgements (read-only) for their dispatched trips, but no acknowledge buttons.

Cannot access Party master, cannot see other parties’ data, cannot access admin screens.

SITE (token-based, limited)

SITE access is via a special link/token per Party/Order (or per site user mapped to specific party/order).

SITE sees ONLY: list of trips for that party/order + ARRIVED and LEFT buttons.

On ARRIVED: mandatory receiver name + timestamp.

On LEFT: mandatory receiver name + timestamp.

Do NOT ask for received quantity (invoice as per dispatch).

SITE cannot create dispatch, cannot view other parties, cannot view admin/plant data.

When Party is marked ‘Reconciled & Invoiced’ or Inactive, SITE token becomes inactive and shows ‘Access Closed’.
